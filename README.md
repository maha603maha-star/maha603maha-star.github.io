To-Do List Web App
This is a simple To-Do List application developed using HTML, CSS and JavaScript.
The application allows users to add tasks, mark tasks as completed and delete tasks. Users can also filter tasks based on their status such as All, Pending and Completed.
Features
Add new tasks
Mark tasks as completed
Delete tasks
Filter tasks
Real-time task count
Responsive design
Technologies Used
HTML
CSS
JavaScript
How to Run
Download the project files.
Open the project folder in VS Code.
Run index.html using Live Server.
